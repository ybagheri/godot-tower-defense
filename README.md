# ci-assets

Godot 4.7.2-stable Android export templates, extracted from the official
release pack so CI never needs the 1.28 GB tpz download.

Provenance: https://github.com/godotengine/godot/releases/tag/4.7.2-stable
(members templates/android_debug.apk, templates/android_release.apk).
Refresh by replacing these files when bumping GODOT_VERSION in ci.yml.
